# 玉见 · 从原石到成器

红山文化主题的**交互数字文创**作品：在浏览器里选一件红山玉器，跟着八道工序，把一块原石一步步「切」成器。

在线试玩：https://yujian-jade-craft.app.workbuddy.host/?sharecode=K4KOEGFXJU

---

## 这是什么

不是文物图录，也不是资料页。玩法是**减法**——玉作的本质是从整块料里减去多余的部分。
你选一件器物（卷身玉器 / 玉鳖 / 玉鸮 / 瓦纹饰 / 玉鱼），然后依次走过八道工序：
相料、开料、打样、粗坯、细琢、钻孔、抛光、成器。

有撤回、有手记、有五档难度、有器物图鉴。做坏了可以退回去重来，但退一步要付代价。

五件器物都做了**几何判定**：孔位偏了、刃口钝了、比例错了，器物就成不了器——不是抽奖，是手艺。

## 技术

- 纯前端静态站，无构建、无依赖、无框架
- Canvas 2D 渲染，玉料以原图做纹理采样
- 全部资源本地化，不请求任何第三方 CDN
- 图片用 WebP（原 26.8 MB → 2.3 MB）
- 字体为「演示佛系体」子集，549 KB（OFL 1.1，允许嵌入网站）

## 文化表述

- 「玉神人兽像」为市场俗称「太阳神」，本作统一用考古学称谓
- 牛首玉人主流解读为戴动物头形冠的巫师 / 萨满，非「兽面人身」
- 八道工序为**简化互动演绎**，不是考古工艺复原
- 首页插画为当代红山主题创作，非出土壁画或遗址原貌复原
