# 玉见 · 从原石到成器

红山文化主题的**交互数字文创**作品：在浏览器里选一件红山玉器，跟着八道工序，把一块原石一步步「切」成器。

在线试玩：**https://baiyu1770-sudo.github.io/yujian/**

备用地址（部分校园网对 GitHub 有干扰时用）：https://yujian-jade-craft.app.workbuddy.host/?sharecode=K4KOEGFXJU

## 这是什么

不是文物图录，也不是资料页。玩法是**减法**——玉作的本质是从整块料里减去多余的部分。
你选一件器物（卷身玉器 / 玉鳖 / 玉鸮 / 瓦纹饰 / 玉鱼），然后依次走过八道工序：
相料、开料、打样、粗坯、细琢、钻孔、抛光、成器。
其中「切片取板」要把料切成一块长方形玉板：上、右、下、左四条边各切一刀，四刀齐了才取板。

有撤回、有手记、有五档难度、有器物图鉴。做坏了可以退回去重来，但退一步要付代价。

五件器物都做了**几何判定**：孔位偏了、刃口钝了、比例错了，器物就成不了器——不是抽奖，是手艺。

## 移动端

`≤950px` 进入工坊后走「一屏操作」布局，桌面三栏不变：

- 顶部吸顶引导条：第 N/8 步 → 工序名 → 进度轨 → 本步完成度 → 祈使句动作指令 → 手势提示，点开可看本步详解
- 画布满幅（390px 屏为 390×390），去掉轴字与角标；进入工坊自动落到操作台
- 正文不小于 14px、辅助不小于 12px；按钮与步骤控件的触控高度不小于 44px
- 首次进入有三步气泡引导（画布 → 引导条 → 撤回），记在本机，可跳过
- 每道工序第一次进入时弹「起 / 走 / 成」三行说明卡；画布上同时给出起手红点与方向箭头，回答「从哪按、往哪滑」
- 说明卡 16 秒自动收起，也可点知道了/×；随时点画布右上角「?」重开

## 文化表述

- 「玉神人兽像」为市场俗称「太阳神」，本作统一用考古学称谓
- 牛首玉人主流解读为戴动物头形冠的巫师 / 萨满，非「兽面人身」
- 八道工序为**简化互动演绎**，不是考古工艺复原
- 首页插画为当代红山主题创作，非出土壁画或遗址原貌复原
